# Data

## Folders

| Folder | Contents |
|---|---|
| `raw/` | Session CSV files copied from the microSD card, renamed (see below). Never edited by hand. |
| `processed/` | Files generated by the analysis scripts. Safe to delete and regenerate. |
| `session_log.csv` | One row per session: WHOOP sleep metrics and confounds. Create it by copying `session_log_template.csv`. |

## Raw file format

Each file is one power-up of the device (one session). Example:

```
time_ms,x,y,z
3021,0.012,-0.031,0.008
3031,0.015,-0.027,0.004
...
```

| Column | Unit | Meaning |
|---|---|---|
| `time_ms` | ms | Milliseconds since the device powered on (not clock time) |
| `x`, `y`, `z` | m/s² | Linear acceleration on the sensor's axes, gravity removed |

Samples arrive every ~10 ms (100 Hz). The last row may be incomplete if power was cut mid-write; the analysis script skips it.

## File naming

Rename each file from the card the same day it's recorded:

```
YYYY-MM-DD_sNN.csv        study session NN (01, 02, …)
YYYY-MM-DD_pilot.csv      pilot / test sessions (excluded from the study analysis)
```

Example: `run004.csv` recorded on Nov 3 as session 7 → `2026-11-03_s07.csv`.

## Session log columns

| Column | Unit / format | Source |
|---|---|---|
| `session_id` | s01, s02, … | |
| `date` | YYYY-MM-DD | |
| `raw_file` | filename in `raw/` | |
| `include` | yes / no | `no` if the session is unusable (note why) |
| `time_first_sprint` | HH:MM (24 h) | |
| `sleep_duration_h` | hours, decimal | WHOOP |
| `sleep_performance_pct` | % | WHOOP |
| `recovery_pct` | % | WHOOP |
| `hrv_ms` | ms | WHOOP |
| `resting_hr_bpm` | bpm | WHOOP |
| `temp_f` | °F | Weather app |
| `wind` | none / light / moderate / strong (+ head/tail) | Observation |
| `surface` | dry / damp / wet | Observation |
| `soreness_1_10` | 1–10 | Self-rating before session |
| `prior_day_strain` | WHOOP day strain | WHOOP |
| `prior_day_load` | rest / light / moderate / hard | Self-report |
| `notes` | free text | Anything unusual |

WHOOP values are for the **night before** the session (the morning-of reading).
